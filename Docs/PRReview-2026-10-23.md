## Native workflow contract

Safience on Mac is a browser workspace: windows own focus and presentation; spaces own bookmarks, pins and sign-in stores. Shared models do not replace Mac command behavior.

| Object | Commands and input | Window and restoration contract | Recovery and verification |
|---|---|---|---|
| Tabs and pins | Standard tab commands, menu equivalents, page retains its keys | Selection belongs to a window; unpin preserves the live page; snapshots match navigation revision | Closed URL is not a recovered unsaved draft; test two windows and remote unpin while editing |
| Bookmarks | Mouse, Command-click, keyboard, VoiceOver and escape | Temporary panel closes on outside click/space change; restore focus to its entry point | Test empty/long/folder lists, narrow window, accessibility focus and cancellation |
| History | Search, filters, context menu, explicit destructive scope | Queries keep their filter; displayed dates match that filter | Verify hidden-device deletions, offline clear, failure/retry and large text |
| Extensions | App menus and Settings, no overridden standard shortcuts | Sheets attach to the initiating window, even with no browser window | Structured update results, consistent removal confirmation, keyboard management |
